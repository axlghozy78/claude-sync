Commands like `/screenwriting-beats` in `_main.md` mean: read `screenwriting-beats/SKILL.md`.

Router. Read only the file(s) below that match the task, then follow them. Paths are relative to this folder. Sub-skill docs are partly in Chinese; reply in the user's language.

- `_main.md`: main workflow (story wiki, structure theory: Vogler, McKee, Save the Cat)
- `screenwriting-beats/SKILL.md`: view, edit or generate the Save the Cat 15-beat sheet
- `screenwriting-character/SKILL.md`: create or edit character cards and relationships
- `screenwriting-ingest/SKILL.md`: extract story elements from raw material files
- `screenwriting-lint/SKILL.md`: structural health check of a story or screenplay
- `screenwriting-refactor/SKILL.md`: restructure the story under theory constraints
- `screenwriting-reimagine/SKILL.md`: creative rewrite as a new version (new lead, storyline, world)
- `screenwriting-export/SKILL.md`: export outline, character sheet, script skeleton
